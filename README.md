# Healthcare Predictive Analytics: Heart Disease Risk Screening

## Overview
This project builds a machine learning workflow to predict heart disease status using demographic, clinical, lifestyle, and anthropometric patient data.

## Business Problem
Healthcare providers need scalable tools to prioritize patients for cardiovascular follow-up and preventive care.

## Dataset
The dataset contains 70,000 patient examination records with features including age, blood pressure, cholesterol level, glucose level, smoking, alcohol use, physical activity, height, weight, occupation, country, and disease status.

## Methods
- Data quality validation
- Clinical outlier handling
- Feature engineering
- Exploratory data analysis
- Model comparison
- Hyperparameter tuning
- Threshold analysis
- Model interpretation

## Models
Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, KNN, and optional XGBoost.

## Evaluation
Accuracy, precision, recall/sensitivity, specificity, F1-score, ROC-AUC, confusion matrix, and threshold tradeoff analysis.

## Key Business Value
The workflow demonstrates how predictive analytics can support cardiovascular risk screening, patient outreach prioritization, and preventive-care planning.

## Disclaimer
This project is for analytics and portfolio demonstration. It is not a medical device or standalone diagnostic tool.
